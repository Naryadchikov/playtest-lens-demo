# Playtest Lens: live demo

The static site behind https://naryadchikov.github.io/playtest-lens-demo/: the reports Playtest Lens made from two real playtests of the same Godot level, with their clips. No code lives here.

- **The code, the Godot add-on and how it works:** [github.com/Naryadchikov/playtest-lens](https://github.com/Naryadchikov/playtest-lens).
- **What is here:** the front page (`index.html`), Player 1's report in normal mode (Muse Spark 1.2 through the Meta Model API) and in open-weights mode (Muse Spark Open on Baseten), Player 2's report (a held-out session, nothing tuned on it), the clips each report plays, the README's GIF and the link preview image.
- **The players** agreed to share their sessions, voices included, for the hackathon submission and this demo.
- **The test level** is the COGITO demo by Phazorknight (MIT), prior work, played in the fork [cogito-playtest-lens](https://github.com/Naryadchikov/cogito-playtest-lens).

Built for the Meta Global AI Developer Hackathon, 2026.
